This project analyzes county-level data from the American Community Survey (ACS), which includes demographic and economic variables such as population, income, poverty rates, and employment composition across over 3,000 U.S. counties. Each observation represents a county, allowing for comparison across different geographic areas. The main question explored is whether the percentage of professional workers is related to median household income. Using data analysis, visualization, and linear regression, the results show a clear positive relationship between professional employment and income. Specifically, counties with higher percentages of professional workers tend to have higher median household incomes, with the model explaining about 35% of the variation in income. Overall, this suggests that professional employment is an important factor associated with income differences across counties, although other factors also contribute.
